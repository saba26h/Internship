# Day 1 - Environment Setup & Jupyter Notebook Workflow ⚙️

## Overview

The first day focused on preparing the development environment and understanding the workflow used in Data Science projects.

The goal was to learn how to create an organized and reproducible Python environment and become familiar with using Jupyter Notebook for interactive programming and experiments.

---

## Topics Covered

### Python Environment Setup

I learned how to prepare a Python environment for projects and why isolated environments are important when working with different libraries and applications.

The topics included:

- Installing and configuring Python.
- Understanding Python environments.
- Creating and managing virtual environments using venv.
- Installing and managing packages using pip.

---

### Dependency Management

I learned how to manage project dependencies and keep track of the libraries used in a project.

This included understanding the purpose of requirements files and how they help recreate the same environment when moving a project to another device.

---

### Jupyter Notebook Workflow

I learned how to work with Jupyter Notebook as a tool for Data Science development.

The topics included:

- Understanding the difference between code cells and Markdown cells.
- Running and organizing Python code interactively.
- Documenting experiments and notes.
- Creating a clear workflow for Data Science tasks.

---

## Tools Used

- Python
- Jupyter Notebook
- VS Code
- pip
- venv
- Git & GitHub

---

## Key Takeaways

By the end of this day, I learned how to set up a Python environment, manage project dependencies, and use Jupyter Notebook as an interactive environment for Data Science tasks.

This foundation will help me work more efficiently on upcoming AI and Data Science projects.
