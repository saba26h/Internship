# Day 2 - Python for Data Science 🐍

## Overview

On the second day of the internship, I focused on Python for Data Science and strengthened my programming skills by learning important Python concepts used in data analysis and AI projects.

The main goal of this day was to improve my understanding of Python programming, write cleaner and more organized code, and learn how different programming concepts can be applied when working with data.

---

## Topics Covered

## Python Functions

I learned how to use functions to organize code and make it more reusable and efficient.  
The topics included creating functions, working with parameters and return values, understanding different types of arguments, and improving code structure by reducing repetition.

Functions helped me understand how to divide large problems into smaller and more manageable parts.

---

## Object-Oriented Programming (OOP)

A major part of this day was learning the fundamentals of Object-Oriented Programming in Python.

I learned how to use classes and objects to organize code and represent real-world entities in programming. The concepts covered included creating classes, working with objects, understanding attributes and methods, and using constructors to initialize object data.

I also learned how OOP helps in writing cleaner, reusable, and easier-to-maintain code by organizing related data and behaviors together.

The focus was on understanding how object-oriented design can be useful when building larger applications and data-driven projects.

---

## Python Data Structures

I practiced working with different Python data structures that are commonly used when handling and organizing data.

The topics included:

- Lists for storing and managing collections of data.
- Dictionaries for representing data using key-value relationships.
- Tuples for storing fixed and immutable data.
- Sets for managing unique values.

I learned how to choose the suitable data structure depending on the type of data and the required operations.

---

## List Comprehension

I learned the concept of list comprehension and how it can be used to write shorter and cleaner Python code.

This helped me understand a more Pythonic way of creating and processing lists while improving code readability and efficiency.
