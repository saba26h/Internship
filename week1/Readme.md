# Week 1 - AI & Data Science Internship 🚀

## Overview

During the first week of the internship, I started building the foundation needed for AI and Data Science projects.

The focus of this week was preparing the Python development environment, understanding the workflow used in Data Science, strengthening Python programming concepts, and getting introduced to NumPy for numerical computing.

---

## Completed Days

### Day 1 - Environment Setup & Jupyter Notebook Workflow ⚙️

Focused on setting up the Python development environment and learning the Jupyter Notebook workflow.

**Covered:**

- Python environment setup.
- Virtual environments and package management.
- Working with pip and requirements files.
- Organizing and documenting work using Jupyter Notebook.

---

### Day 2 - Python for Data Science 🐍

Focused on improving Python programming skills and learning concepts used in Data Science workflows.

**Covered:**

- Functions and code organization.
- Object-Oriented Programming (OOP).
- Python data structures.
- List comprehension.
- Writing cleaner and more reusable Python code.

---

### Day 3 - Introduction to NumPy 🔢

Focused on learning the basics of NumPy, the core library for numerical computing in Python and an essential tool for AI and Data Science.

**Covered:**

- Creating NumPy arrays in different ways.
- Understanding array shape and data types.
- Indexing and slicing arrays.
- Boolean masking.
- Vectorized operations.
- Broadcasting.
- Basic array statistics such as sum and mean.

---

## Week 1 Progress

So far, I have built a stronger understanding of Python development workflow, strengthened my Python programming fundamentals, and started working with NumPy for efficient numerical computing. These skills provide the foundation for upcoming Data Science and AI tasks.
