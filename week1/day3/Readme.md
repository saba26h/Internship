# Day 3 - Introduction to NumPy 🔢

## Overview

The third day focused on learning the fundamentals of NumPy, which is one of the most important Python libraries for numerical computing and a core tool used in Data Science and AI.

The goal of this day was to understand how NumPy handles numerical data efficiently, work with arrays, perform mathematical operations, and learn the concepts that make data processing faster compared to traditional Python methods.

---

## Topics Covered

### Introduction to NumPy

I learned why NumPy is widely used in Data Science and AI projects and how it provides efficient tools for working with numerical data.

The topics included:

- Understanding the role of NumPy in the Data Science ecosystem.
- Learning the difference between Python lists and NumPy arrays.
- Understanding why NumPy operations are faster and more efficient for numerical computing.
- Working with the basic structure of NumPy arrays.

---

### Creating NumPy Arrays

I learned different ways to create NumPy arrays depending on the requirements of the task.

The topics included:

- Creating arrays from existing data.

- Creating sequences of numbers.
- Understanding different array creation methods.

I learned how to inspect and understand the structure of NumPy arrays.

The topics included:

- Understanding array dimensions.
