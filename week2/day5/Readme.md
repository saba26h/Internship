# Day 5 - Exploratory Data Analysis (EDA) Part 2: Correlation & Data Storytelling 📊

## Overview

The fifth day focused on completing the Exploratory Data Analysis workflow by studying relationships between variables and extracting meaningful insights from datasets.

The goal was to move from analyzing individual variables to understanding relationships between features using bivariate analysis, correlation analysis, and advanced visualization techniques.

---

## Topics Covered

### Bivariate Analysis

I learned how to analyze relationships between two variables.

The topics included:

* Understanding relationships between features before modeling.
* Performing analysis between numerical and categorical variables.
* Identifying patterns and differences using visualization techniques.

---

### Scatter Plots

I learned how scatter plots are used to visualize relationships between numerical variables.

The topics included:

* Creating scatter plots using `sns.scatterplot()`.
* Understanding positive and negative relationships.
* Identifying trends and unusual observations.

---

### Grouped Box Plots

I learned how grouped box plots compare numerical distributions across categories.

The topics included:

* Creating grouped box plots using `sns.boxplot()`.
* Comparing distributions between groups.
* Understanding differences in median and spread.

---

### Correlation Analysis

I learned how correlation measures relationships between numerical variables.

The topics included:

* Calculating correlation matrices.
* Understanding correlation values between -1 and +1.
* Identifying strong and weak relationships.
* Understanding that correlation does not mean causation.

---

### Correlation Heatmap

I learned how to visualize correlations between multiple variables.

The topics included:

* Creating correlation matrices using Pandas.
* Visualizing correlations using `sns.heatmap()`.
* Identifying important relationships between features.

---

### Pairplot

I learned how pairplots provide a complete overview of relationships between numerical variables.

The topics included:

* Creating pairplots using `sns.pairplot()`.
* Comparing multiple variables simultaneously.
* Discovering patterns that require further analysis.

---

### Data Storytelling

I learned how to transform analysis results into understandable insights.

The topics included:

* Writing observations based on visualizations.
* Explaining discovered patterns.
* Communicating findings clearly.
* Understanding that analysis is incomplete without interpretation.

---

## Hands-On Lab

During this day, I created a complete EDA notebook that combined all learned concepts.

The implementation included:

* Loading and exploring a real dataset.
* Applying descriptive statistics.
* Handling missing values.
* Detecting and handling outliers.
* Performing univariate and bivariate analysis.
* Creating correlation matrices and heatmaps.
* Using pairplots to analyze relationships.
* Writing data-driven conclusions.
