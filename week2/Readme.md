# Week 2 - Statistics, Probability & Exploratory Data Analysis 📊🚀

## Overview

During the second week of the internship, I focused on building the mathematical and analytical foundations required for Machine Learning and Data Science.

The focus of this week was understanding descriptive statistics, probability fundamentals, linear algebra concepts used in machine learning, and performing Exploratory Data Analysis (EDA) using statistical techniques and data visualization tools.

---

# Completed Days

## Day 1 - Descriptive Statistics 📈

The first day focused on understanding how to summarize and describe datasets using statistical measures.

I learned how to identify the center of a dataset, measure its variability, and understand the impact of outliers on different statistical measures.

**Topics Covered:**

* Mean, Median, and Mode.
* Variance and Standard Deviation.
* Range and Interquartile Range (IQR).
* Percentiles and Quartiles.
* Interpreting descriptive statistics.
* Understanding the effect of outliers on statistical measures.

---

## Day 2 - Probability & Distributions 🎲

The second day focused on understanding probability concepts and probability distributions, which are essential for handling uncertainty and making predictions in Machine Learning.

I learned how to calculate probabilities, apply probability rules, understand conditional probability and Bayes' theorem, and recognize common probability distributions used in data analysis.

**Topics Covered:**

* Probability basics and measuring uncertainty.
* Complement, addition, and multiplication probability rules.
* Conditional probability P(A|B).
* Bayes' theorem and its role in Machine Learning.
* Normal, Binomial, and Uniform distributions.
* Applying probability concepts using Python and statistical libraries.
