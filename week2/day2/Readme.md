
# Day 2 - Probability & Distributions 🎲

## Overview

The second day focused on learning the fundamentals of Probability and Probability Distributions and understanding how uncertainty is represented and analyzed in data.

The goal was to learn how to calculate probabilities, apply probability rules, understand conditional probability and Bayes' theorem, and recognize common probability distributions used in Machine Learning.

---

## Topics Covered

### Probability Basics

I learned the fundamental concepts of probability and how to measure the likelihood of events.

The topics included:

* Understanding probability as a measure of uncertainty.
* Calculating probability using favorable outcomes over total possible outcomes.
* Understanding probability values between 0 and 1.
* Applying probability concepts to real-world and Machine Learning examples.

---

### Probability Rules

I learned the main rules used to calculate probabilities for different events.

The topics included:

* Applying the Complement Rule.
* Understanding the Addition Rule.
* Applying the Multiplication Rule for independent events.
* Understanding the difference between dependent and independent events.

---

### Conditional Probability

I learned how conditional probability describes the probability of an event based on additional information.

The topics included:

* Understanding conditional probability P(A|B).
* Applying the conditional probability formula.
* Calculating probabilities when a condition is already known.
* Understanding the importance of conditional probability in Machine Learning predictions.

---

### Bayes' Theorem

I learned how Bayes' theorem updates probabilities when new evidence becomes available.

The topics included:

* Understanding prior probability.
* Understanding likelihood.
* Understanding posterior probability.
* Learning how Bayes' theorem is used in Machine Learning models such as Naive Bayes.

---

### Probability Distributions

I learned how probability distributions describe the behavior and spread of data.

The topics included:

* Understanding the concept of probability distributions.
* Recognizing the Normal (Gaussian) Distribution.
* Understanding the Binomial Distribution.
* Understanding the Uniform Distribution.
* Identifying examples of different distributions in real-world data.

---

### Applying Probability to Data Analysis

I learned how to implement probability concepts using Python and statistical libraries.

The topics included:

* Simulating probability experiments using NumPy.
* Generating and visualizing probability distributions.
* Calculating conditional probability using datasets.
* Interpreting probability results and their meaning.

## Key Takeaways

By the end of this day, I learned how to apply probability concepts, calculate different types of probabilities, and understand how probability distributions describe data behavior.

These concepts provide an important foundation for Exploratory Data Analysis and Machine Learning, where models use probability to make predictions and handle uncertainty.
