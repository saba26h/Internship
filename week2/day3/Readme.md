# Day 3 - Linear Algebra for Machine Learning 🔢

## Overview

The third day focused on understanding the fundamental concepts of Linear Algebra and their importance in Machine Learning.

The goal was to learn how data is represented mathematically, how samples are stored as vectors and matrices, and how models use operations like dot product and matrix multiplication to generate predictions.

---

## Topics Covered

### Why Linear Algebra is the Language of Machine Learning

I learned why Linear Algebra is considered the mathematical foundation of Machine Learning.

The topics included:

* Understanding why datasets are represented as matrices.
* Understanding how models use vectors and matrices internally.
* Learning the role of mathematical operations in Machine Learning algorithms.

---

### Vectors in Machine Learning

I learned how vectors represent individual data samples.

The topics included:

* Creating vectors using NumPy arrays.
* Representing a single sample using its features.
* Understanding vector dimensions and shapes.

---

### Matrices and Dataset Representation

I learned how datasets are represented using matrices.

The topics included:

* Creating matrices using NumPy.
* Understanding rows as samples and columns as features.
* Checking matrix dimensions using the shape attribute.
* Understanding the relationship between samples, features, and matrix size.

---

### Dot Product and Model Predictions

I learned how the dot product is used to calculate predictions in Machine Learning models.

The topics included:

* Understanding the dot product operation.
* Computing dot products manually and using NumPy.
* Understanding the relationship between features, weights, and predictions.
* Learning how linear models use dot products internally.

---

### Matrix Multiplication

I learned how matrix multiplication allows Machine Learning models to process multiple samples efficiently.

The topics included:

* Performing matrix multiplication using NumPy.
* Understanding the shape-matching rule.
* Applying matrix multiplication between datasets and weight vectors.
* Understanding and fixing shape mismatch errors.

---

## Key Takeaways

By the end of this day, I learned how data is represented using vectors and matrices in Machine Learning.

I understood how dot products and matrix multiplication are used to perform predictions and why understanding dimensions and shapes is essential when working with Machine Learning models.

These Linear Algebra concepts provide the mathematical foundation needed for understanding and implementing Machine Learning algorithms.
