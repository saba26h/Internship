
# Day 1 - Supervised Learning Concepts & Scikit-learn API 🤖📊

## Overview

The first day focused on understanding the fundamentals of Supervised Learning and the basic workflow used to build Machine Learning models.

The goal was to understand how models learn from labeled data, differentiate between regression and classification tasks, learn the structure of a Machine Learning workflow, and get familiar with the Scikit-learn API used for implementing models in Python.

---

## Topics Covered

### Introduction to Supervised Learning

I learned the fundamental concepts of supervised learning and how Machine Learning models learn patterns from labeled datasets.

The topics included:

* Understanding what supervised learning is.
* Learning the difference between features (X) and target variables (y).
* Understanding labeled data and its importance in model training.
* Exploring how models learn relationships between input data and outputs.
* Understanding the basic idea of prediction using trained models.

---

### Regression and Classification Concepts

I learned how to identify the two main types of supervised learning problems.

The topics included:

* Understanding Regression problems and predicting continuous numerical values.
* Understanding Classification problems and predicting discrete categories.
* Comparing regression and classification tasks.
* Identifying the appropriate learning approach based on the target variable.

---

### Machine Learning Workflow

I learned the general workflow used when developing supervised learning models.

The topics included:

* Loading and preparing datasets.
* Separating features (X) from the target (y).
* Splitting data into training and testing sets.
* Understanding the purpose of training and evaluation phases.
* Following the standard steps for building Machine Learning models.

---

### Scikit-learn API Basics

I learned the structure and usage of the Scikit-learn API for implementing Machine Learning models.

The topics included:

* Understanding the common structure of Scikit-learn models.
* Importing algorithms and utilities from sklearn.
* Creating model instances.
* Training models using the `fit()` method.
* Making predictions using the `predict()` method.
* Understanding the consistent API design across different ML algorithms.

---

### Data Splitting with Train/Test Split

I learned how to split datasets to prepare them for Machine Learning experiments.

The topics included:

* Using `train_test_split()` from Scikit-learn.
* Understanding training and testing datasets.
* Applying an 80/20 train-test split.
* Using `random_state` to ensure reproducible results.
* Checking dataset shapes after splitting.

## Key Takeaways

By the end of this day, I learned the foundations of supervised learning, understood the difference between regression and classification tasks, and became familiar with the basic Scikit-learn workflow.

These concepts provide the foundation for building, training, and evaluating Machine Learning models in future projects.
