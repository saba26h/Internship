# Day 2 - Linear Regression & Model Evaluation 🤖📈

## Overview

The second day focused on understanding Linear Regression and the process of building and evaluating regression models.

The goal was to learn how Linear Regression predicts continuous values, understand how models generate predictions using learned weights and bias, interpret model coefficients and intercept, and evaluate regression models using different performance metrics with Scikit-learn.

---

## Topics Covered

### Introduction to Linear Regression

I learned the fundamental concepts of Linear Regression and how it is used for predicting continuous numerical values.

The topics included:

* Understanding what Linear Regression is and how it works.
* Learning how models fit the best line through data points.
* Understanding the relationship between features and target values.
* Understanding predictions using weights and bias.
* Connecting Linear Regression with the dot product concept from previous topics.

---

### Training and Predicting with Linear Regression

I learned how to train a Linear Regression model and generate predictions using Scikit-learn.

The topics included:

* Creating a Linear Regression model using Scikit-learn.
* Training models using the `fit()` method.
* Generating predictions using the `predict()` method.
* Understanding the training and prediction process.
* Applying Linear Regression to regression datasets.

---

### Interpreting Model Coefficients and Intercept

I learned how to interpret the parameters learned by a Linear Regression model.

The topics included:

* Understanding model coefficients as feature weights.
* Learning how each feature affects the prediction.
* Understanding the role of the intercept (bias).
* Identifying the features with the strongest influence on predictions.

---

### Regression Evaluation Metrics

I learned how to evaluate regression models using different performance metrics.

The topics included:

* Understanding Mean Absolute Error (MAE).
* Understanding Root Mean Squared Error (RMSE).
* Understanding R² score.
* Comparing different evaluation metrics.
* Interpreting model performance based on evaluation results.

---

### Baseline Comparison

I learned the importance of comparing Machine Learning models against a simple baseline.

The topics included:

* Understanding what a baseline model is.
* Creating a baseline that predicts the mean value.
* Comparing model performance with baseline performance.
* Determining whether the model learned useful patterns.

---

## Key Takeaways

By the end of this day, I learned how Linear Regression models work, how to train and use regression models for prediction, and how to evaluate their performance using MAE, RMSE, and R² metrics.

I also learned the importance of comparing models with a baseline to determine whether the model provides meaningful improvements.
